## Project Overview

This project was developed during my first year with Cakrawala Skala for the Singapore Amazing Flying Machine Competition 2024. As an Electrical Division Member, I contributed to the development and integration of a glove-based control interface for a semi-autonomous drone, designed to enable intuitive gesture-based piloting and create a more natural human–drone interaction experience. 

My work focused on integrating an ESP32 microcontroller running FreeRTOS with IMU sensors, supporting electrical wiring and embedded system prototyping, and developing a custom receiver module to decode control signals transmitted over 2.4 GHz Wi-Fi using the UDP protocol. 

I also supported hardware-software integration, system debugging, and functional validation to improve reliability during testing. The completed platform allowed the drone to respond to the user's hand movements in real time and qualified for the semifinal round, placing 8th overall in our first year of participating in SAFMC.
