## Project Overview

This project was developed as my undergraduate final project at Politeknik Elektronika Negeri Surabaya. I designed and implemented an Adaptive Cruise Control system for a 1:10-scale Ackermann mobile robot to maintain a safe following distance and stable speed relative to a preceding vehicle or dynamic obstacle. 

The system integrated LiDAR-based distance measurements and encoder feedback for real-time distance and velocity monitoring, while a Fuzzy Social Force Model-based control strategy was used to determine the robot's speed response. 

Particle Swarm Optimization was applied to optimize the control parameters and improve following-distance response, speed stability, and overall system performance.
